Install

Three steps, about two minutes

STEP 1

Open a terminal on the box

Use SSH or Telnet (PuTTY on Windows) to your receiver's IP address, user root.

STEP 2

Paste the command

Choose the skin

Posters

A film or series poster, its rating and a short plot, shown with the infobar. The poster follows the programme: Now and Next each get their own artwork in the second infobar.

Install

  1. Press MENU › Obsidian Apps, then pick Posters and install it.
  2. Make a free account on themoviedb.org, then Settings › API: copy the API key.
  3. In Posters, open TMDB key and scan the QR code with your phone to paste the key (or use a tmdb.txt file, or the remote).
  4. Choose the Poster folder on your USB or hard disk. Posters appear the next time you zap.

Poster folder
The USB or hard disk drive used for posters. Never the receiver's flash.
Posters for
Films, series and documentaries, films only, or films and series. News, sport and shows never get a poster.
Backdrops
On: a film still fills the background of the Floating and Slate channel lists. Off by default.
Cache size
50, 100 or 200 MB. The oldest posters are deleted above this size.
Poster time
5, 8, 10 or 15 s after a zap. In the Glass infobar it keeps the infobar open as long.
Slide in

Position
Top right or top left. Applies after a GUI restart.
Cache

Troubleshooting

“Storage is on the receiver flash”, but I picked my hard disk

Fixed in 1.0.4 for images that run from the hard disk (OpenMultiboot, EgamiBoot, NeoBoot). Update Posters from Obsidian Apps.

No poster appears for a programme

Posters need a programme guide with a title the film database knows. News, sport and live shows never get one; the infobar then shows the picon.

“TMDB refused this key”

Copy the API key (not the access token) from themoviedb.org › Settings › API and enter it again.

Install

  1. Press MENU › Obsidian Apps, pick Stream and install it.
  2. Open Stream and press GREEN to turn streaming on (it is off until you do).
  3. In your IPTV app, add an Xtream Codes playlist with the Server, Username and Password shown on the TV, or paste the M3U link into VLC.
  4. To take the TV back while a device watches, press OK on the remote.

Troubleshooting

The app cannot log in

Use the same home network (not a guest Wi-Fi). After 5 wrong passwords the device waits 1 minute. On iPhone, allow Local Network for the app in Settings › Privacy & Security.

The app says “busy”

Another device is watching, or OK was pressed a moment ago (the device is refused for the time you set).

New bouquets do not show in the app

Refresh the playlist in the IPTV app after adding or renaming bouquets.

Live Subtitles

Subtitles and translation in 25 languages, on your PC or with Groq. Adapts to your PC by itself.

Latest version1.1.0 beta
NeedsObsidian FHD 1.8.1+
Installscoming soon
Download .ipk Install from the receiver

Needs ffmpeg (installed with the app) and a speech server: a free Groq key (cloud) or Docker on a PC at home.

On this page Install PC server Upgrade an existing installation Receiver setup Languages and first use Slow or older PC Privacy Settings Troubleshooting What's new

Install

  1. Install or update Live Subtitles in Obsidian Apps, then restart the receiver GUI.
  2. To keep everything at home, follow PC server, then Receiver setup.

Privacy: with Groq, short clips of the channel's sound go to Groq. With your PC, sound and text stay at home. The Groq key is kept in a file only the system can read and never appears in the log.

PC server

Your PC does the speech recognition and translation, so the sound stays at home. It only needs Docker; no graphics card. The PC and the receiver must be on the same home network.

  1. Install Docker Desktop (Windows or Mac) from docker.com, start it and wait until it says Engine running. On Linux, install Docker Engine with the Compose plugin.
  2. Paste this line and press Enter. Windows: open PowerShell from the Start menu. Mac/Linux: open a terminal. It downloads the setup, checks it, installs it in the obsidian-subtitles folder of your user folder and runs it.
    Windows (PowerShell)
    irm https://github.com/dali44g/Obsidian-FHD/releases/download/subtitles-local-v3/install.ps1 | iex
    Mac / Linux
    curl -fsSL https://github.com/dali44g/Obsidian-FHD/releases/download/subtitles-local-v3/install.sh | sh
  3. The setup adjusts itself to your PC, starts the servers, checks them and prints the PC address to type on the receiver.

Or with the ZIP: download the setup ZIP, extract it to a folder you will keep, for example Documents\obsidian-subtitles, and run the setup in that folder. Windows: right-click setup.ps1 › Run with PowerShell, or type the first command below in a terminal opened in the folder. Mac/Linux: the second command.

Windows
powershell -ExecutionPolicy Bypass -File .\setup.ps1
Mac / Linux
sh setup.sh

Later, to check the servers again: docker compose run --rm check in the setup folder. Windows may ask to allow Docker on private networks: answer yes. Never open ports 8000/5000 on your router.

Upgrade an existing installation

  1. If the old servers were set up in another folder, stop them there with docker compose down (never add -v: it deletes the downloaded models). Containers made by hand (speaches, obsidian-translate, libretranslate): stop and remove only those; their volumes and folders stay.
  2. Paste the line from PC server again. Run a second time, it upgrades: your .env and downloaded models are kept, the program files are replaced. With the ZIP: extract it over your setup folder and run the setup.
  3. Old translation models in another folder (for example D:/obsidian-translate/argos, or models in an older setup folder)? Open .env in the setup folder, write MODELS=D:/obsidian-translate (the folder that contains argos) and run the setup again. The speech models already downloaded are kept.
  4. Update Live Subtitles on the receiver and restart its GUI.

Receiver setup

  1. MENU › Obsidian Apps › Live Subtitles › YELLOW.
  2. Speech server = Local server (PC), PC address = the address the setup printed, for example 192.168.1.20:8000.
  3. Choose the Spoken language (or Auto) and the Subtitle language. Leave everything else as it is.
  4. Back on the app page, the line under the tiles says when the PC is ready. The first time it downloads the models: playback continues meanwhile.
  5. GREEN starts the subtitles. OK tests a few seconds of sound.

Slow or older PC

Nothing to set. The setup adapts to your PC, and while you watch, the app measures how fast the PC answers. If it cannot keep up, Speech model = Recommended switches by itself to a smaller model (medium › small › base) and says so in the status line. It is remembered for that PC and the better model is tried again after a week, or at once with Settings › PC speed.

Smaller models are a little less exact, mostly for Arabic, Persian and the Balkan languages. If even the smallest model is too slow, the app suggests Groq (free, in the cloud), which needs no PC.

Privacy

With your PC, sound and text stay at home; only the model downloads use the internet. A saved Groq key is not used for translation unless you turn on Allow cloud fallback. Choosing Groq as the speech server sends short sound clips to Groq.

Troubleshooting

“Not answering” or the PC address does not work

Check that Docker Desktop is running and the PC is not asleep. Run docker compose run --rm check in the setup folder. On the receiver use the address the setup printed (not localhost), with :8000.

Subtitles come late or “Server too slow”

The app switches to a smaller model by itself after a few seconds (see Slow or older PC). Close heavy programs on the PC, or give Docker more CPUs and memory in Docker Desktop › Settings › Resources.

A download failed

The PC needs internet the first time and enough free space. The app tries again by itself; models that work are never deleted. Details: docker compose logs --tail 100 speech translate.

“PC translator needs updating”

Your PC runs an older setup: follow Upgrade an existing installation.

“Groq limit reached on every key: waiting”

The free Groq plan has hourly and daily limits. Subtitles come back by themselves; a second free key takes over at once. A PC server has no limit.

The network drops

Short drops are not seen. After a longer one the channel plays without subtitles and they come back by themselves.

Something is missing

The line under the tiles says what: the PC address, the Groq key or ffmpeg. BLUE opens the log, BLUE again shows a QR code to send it.

Docker Desktop does not start (Windows)
  • “WSL needs updating” or “WSL 2 is not installed”: open PowerShell as administrator, run wsl --install (or wsl --update), then restart the PC.
  • “Virtualisation” error: in Task Manager › Performance › CPU, check that Virtualisation is Enabled. If not, turn it on in the PC's BIOS (often called VT-x, AMD-V or SVM).
  • Old Windows 10: WSL 2 needs version 2004 or newer. Run Windows Update first.
